# YouTube Analytics Dashboard

## Project Overview

This project analyzes YouTube data to understand video performance and audience engagement. It provides insights that help improve content strategy and support better decision-making.

## Objective

To analyze YouTube video data and identify trends in views, likes, and audience interaction to evaluate content performance.

## Tools Used

* Power BI: Built interactive dashboards and visualized insights
* Microsoft Excel: Cleaned and prepared the dataset

## Key Performance Indicators (KPIs)

* Total Views
* Total Likes
* Total channels
* Engagement Rate

## Key Insights

* Identified top-performing videos based on views and engagement
* Analyzed audience interaction using likes
* Compared performance across different videos
* Observed patterns to improve content strategy
